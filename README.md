# SIRFlow

SIRFlow is a policy-driven framework for transient scientific data governance and automation at large-scale experimental facilities.

This repository accompanies the SIRFlow work presented at the conference and will serve as the public home for the project.

The source code, examples, documentation, and supporting materials are currently being prepared for release and will be transferred to this repository soon.

SIRFlow focuses on the layer between data acquisition, scientific processing, and long-term data cataloguing, providing mechanisms for dataset lifecycle management, policy-driven automation, provenance, reproducibility, and integration with workflow engines, storage systems, HPC resources, and scientific data catalogues.

## Architecture documentation

The project architecture will be documented using the C4 Model, including:

- System Context
- Containers
- Components
- Key interactions between SIRFlow, acquisition systems, workflow engines, storage, HPC resources, and data catalogues

The C4 diagrams will be maintained alongside the implementation so that the software architecture and its responsibilities remain clear as the project evolves.
